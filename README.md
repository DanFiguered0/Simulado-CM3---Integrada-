# Simuladão Integrado — Ciências Médicas III

PWA estático para navegador, pensado para uso em iPhone/iPad e Android.

## Arquivos

- `index.html` — aplicativo principal
- `manifest.webmanifest` — metadados de instalação como app
- `sw.js` — Service Worker para cache e uso com conectividade limitada
- `icons/` — ícones do aplicativo

## GitHub Pages

1. Envie todos os arquivos para a raiz do repositório.
2. Em **Settings → Pages**, selecione **Deploy from a branch**.
3. Selecione `main` e `/ (root)`.
4. Abra o endereço do GitHub Pages.

## iPhone/iPad

Abra o site no **Safari** e use **Compartilhar → Adicionar à Tela de Início**.

## Android

Abra no **Chrome**. Quando o navegador oferecer a opção de instalação, escolha **Instalar app** / **Adicionar à tela inicial**.

> Observação: o Service Worker funciona em HTTPS. GitHub Pages já fornece HTTPS.
